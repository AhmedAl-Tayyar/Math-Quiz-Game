# Math Quiz Game

A simple console-based math quiz game built with C++.

The program generates random math questions based on the selected difficulty level and operation type. It then checks the user's answers and displays the final result.

## Features

- Multiple difficulty levels:
  - Easy
  - Medium
  - Hard
  - Mixed

- Multiple operation types:
  - Addition
  - Subtraction
  - Multiplication
  - Division
  - Mixed operations

- Randomly generated questions
- Automatic answer checking
- Right and wrong answer tracking
- Pass/Fail result
- Console feedback for correct and incorrect answers

## How It Works

The user selects the difficulty level and the type of mathematical operations.

The program then generates a number of random questions and asks the user to solve them.

After each answer, the program checks whether the answer is correct and keeps track of the results.

At the end, the program displays the number of correct and incorrect answers and determines whether the user passed the quiz.
